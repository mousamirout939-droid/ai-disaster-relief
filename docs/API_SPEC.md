# API Specification (Summary)

Full interactive OpenAPI docs are auto-generated by FastAPI at
`/api/v1/docs` (Swagger UI) and `/api/v1/redoc` (ReDoc) — this document is a
high-level index; treat the live OpenAPI schema as the source of truth.

## Auth
| Method | Path                | Auth | Description |
|--------|---------------------|------|-------------|
| POST   | /auth/register      | none | Create a citizen or volunteer account |
| POST   | /auth/login         | none | Exchange credentials for access/refresh tokens |
| POST   | /auth/refresh       | none | Exchange a refresh token for a new access token |
| POST   | /auth/logout        | user | Revoke the current access token |
| GET    | /auth/me            | user | Get the current authenticated profile |

## Incidents
| Method | Path                          | Auth              | Description |
|--------|-------------------------------|-------------------|-------------|
| POST   | /incidents                    | user              | Report a disaster (multipart: images + fields) |
| GET    | /incidents/nearby             | user              | Geo-query incidents within a radius |
| GET    | /incidents                    | user              | Paginated incident list |
| POST   | /incidents/{id}/verify        | volunteer, admin  | Approve/reject a pending report |

## Shelters & Inventory
| Method | Path                                  | Auth              | Description |
|--------|----------------------------------------|-------------------|-------------|
| POST   | /shelters                              | admin             | Create a shelter |
| GET    | /shelters/nearby                       | public/user       | Geo-query shelters |
| PATCH  | /shelters/{id}                         | volunteer, admin  | Update capacity/status |
| DELETE | /shelters/{id}                         | admin             | Remove a shelter |
| GET    | /shelters/{id}/inventory                | user              | List supply inventory |
| PUT    | /shelters/{id}/inventory                | volunteer, admin  | Upsert an inventory item |

## Alerts, Chat, Aid Requests, Analytics, Audit
See `app/api/v1/endpoints/{alerts,chat,aid_requests,analytics,audit}.py` for
full request/response schemas — every route is documented with Pydantic
models that render directly into the OpenAPI schema.

## WebSocket
`GET /ws?token=<access_token>` — real-time channel for `incident.high_severity`,
`alert.broadcast`, and `shelter.capacity_updated` events (see
`app/websockets/events.py` for the full event catalog).
